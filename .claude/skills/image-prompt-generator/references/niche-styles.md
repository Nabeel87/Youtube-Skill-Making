## 🖥️ Tech & AI

| Element | Recommendation |
|---------|----------------|
| Colors | Blue + White, Cyan accents, Neon highlights |
| Lighting | Dramatic side light, RGB glow, screen glow |
| Background | Abstract particles, dark gradient, circuit patterns |
| Subject | Product close-up, glowing interfaces, futuristic devices |
| Mood | Curious, Exciting, Futuristic |

### Example Elements
```
- Holographic interfaces
- Glowing code/data streams
- Sleek devices with light trails
- Person amazed at screen
- Dark background with blue/cyan particles
```

### Best Performing Styles
1. Person reacting to glowing tech
2. Product hero shot with dramatic lighting
3. Before/after comparisons
4. Floating UI elements with user

## Universal CTR Boosters

### Elements That Always Work
1. **Faces with emotion** - 38% higher CTR
2. **High contrast colors** - 30% more visible
3. **Single clear subject** - Better comprehension
4. **Text with contrast** - Readable at small size
5. **Curiosity gap** - Something hidden/revealed

### Elements to Avoid
1. ❌ Cluttered composition
2. ❌ Low contrast colors
3. ❌ Multiple competing subjects
4. ❌ Small unreadable text
5. ❌ Generic stock photo look
