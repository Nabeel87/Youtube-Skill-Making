## Usage in Scripts

When using these terms in TTS scripts:

**First mention:** Use full form or spell out
```
"A.I., or artificial intelligence, is changing..."
```

**Subsequent mentions:** Use abbreviated form
```
"A.I. tools are becoming more powerful..."
```

**Technical audience:** Use common pronunciation
```
"The API endpoint returns JSON data..."
```

**General audience:** Explain briefly
```
"The A.P.I., which is how different software talks to each other..."
```
