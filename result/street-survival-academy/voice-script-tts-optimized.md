## 💡 PRO TIPS FOR BEST TTS RESULTS

### 1. For ElevenLabs Specifically
- **Comma placement** = 0.3s pause (use liberally for natural speech)
- **Period** = 0.5s pause (end of complete thoughts)
- **[pause]** = Write literally to force 1-second pause
- **Ellipsis (...)** = 0.6s thoughtful pause
- **CAPS** = Emphasis (use sparingly, only for key words)
- **Quote delivery** = ElevenLabs handles quotes naturally if you write `quote...` before them

### 2. Pacing Control
- This script is optimized for 150 words per minute = calm educational pace
- If voice sounds too fast: Add more commas and periods
- If voice sounds too slow: Remove some pauses
- Test first 30 seconds, adjust globally based on that

### 3. Emotion Consistency
- Keep "Stability" at 0.65 for documentary consistency
- Don't go above 0.50 on "Style" or it becomes overly dramatic
- For crime prevention content, understated = more trustworthy

### 4. Common TTS Mistakes to Avoid
- Don't use abbreviations (write out "Doctor", not "Dr.")
- Don't use symbols (write "and" not "&")
- Avoid ALL CAPS SENTENCES (sounds like shouting)
- Don't overuse exclamation marks (sounds unnatural)

### 5. Section-by-Section Generation
If your TTS tool has character/length limits:
- Generate each section separately
- Use same voice settings for all sections
- Edit together in audio software (Audacity, Adobe Audition)
- Add 0.5-1 second silence between sections for breathing room

## 🎵 AUDIO POST-PRODUCTION NOTES

### After TTS Generation

**Recommended Edits:**
1. **Add 0.5s silence** at the very beginning (prevents cut-off start)
2. **Add 1.0s silence** at the very end (clean conclusion)
3. **Normalize audio** to -3dB (prevents clipping when mixed with music)
4. **Slight EQ adjustment** if needed:
   - Boost 100-200 Hz slightly for warmth
   - Boost 3-5 kHz slightly for clarity
   - Cut 6-8 kHz if voice sounds harsh
5. **De-esser** if "s" sounds are too sharp
6. **Compression** (gentle) for consistent volume

**Layering with Background Music:**
- Voice: -3dB to 0dB (primary, loud and clear)
- Music: -24dB to -18dB (background, supportive)
- Ambient sounds: -30dB (subtle texture only)
